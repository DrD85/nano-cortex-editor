Morningstar MC6 Pro Export

Creates a bank file for the MC6 Pro: your presets on page 1, their five FX slots on page 2.

Page 1: A–E = your presets, F = FX page. Page 2: A–E = the five FX slots (on/off), F = back. An expression switch moves the Amount of its FX (the AMOUNT knob) between the Min and Max set under Expression in each preset. To read which FX are on, the export loads each selected preset on the Nano for a moment and then returns to the current one. Connect the MC6 Pro to the Nano via USB (MC6 Pro USB Host port).
